## About me

I'm a **Generative AI Engineer** at an HR tech company, where I went from intern to full-time in 2025. I build LLM systems that run in production: skill-graph resume ranking, RAG pipelines on vector databases, and multi-agent candidate screening.

- 🧠 **Building:** LLM ranking and screening systems with **LangChain**, **LangGraph**, **RAG** and **pgvector**
- ⚡ **Impact:** cut LLM costs by **32%** with prompt caching, and latency by **40%** with parallel calls and model routing
- 🛡️ **Care about:** guardrails, deterministic checks on LLM output, and evals that catch regressions
- 🚀 **Ship with:** Next.js, FastAPI, Docker and CI/CD on **Azure AI Foundry**
- 🎯 **Looking for:** Generative AI / LLM engineering roles at product teams building with AI
